# Define Problem Statements — ShopEEZ

## 1. Customer Pain Points & Problem Statements

### Problem Statement 1: Disjointed Shopping Experience on Mobile Devices
- **Context**: Most online consumers shop using mobile or tablet layouts.
- **Pain Point**: Existing small-scale e-commerce applications use cluttered layouts, oversized banners, and poorly-optimized catalog listings, resulting in high shopping-cart abandonment rates.
- **Impact**: Customers fail to browse products comfortably or complete orders, leading to frustration and lost revenue.

### Problem Statement 2: Tedious Checkout and Lost Cart Contents
- **Context**: Customers add items to their carts but might get distracted before finishing checkout.
- **Pain Point**: If a session expires or a page reloads, the shopping cart items are wiped out, forcing the user to find the items all over again.
- **Impact**: Decreased conversion rates and drop-off in user engagement.

---

## 2. Administrator Pain Points & Problem Statements

### Problem Statement 3: Complex and Opaque Inventory Management
- **Context**: Store owners need to quickly add new arrivals, modify pricing, or review out-of-stock notices.
- **Pain Point**: Traditional admin panels are either overly complicated (requiring training) or decoupled from the frontend, making real-time catalog changes tedious to apply.
- **Impact**: Delays in updating product details, leading to orders placed for out-of-stock items.

---

## 3. Product Solution Statement

**ShopEEZ** solves these challenges by providing a responsive, single-page full-stack e-commerce application:
1. **Responsive Vanilla CSS Layouts**: Optimized for mobile and desktop viewports, with a premium dark theme and clean grids to maximize product visibility.
2. **Persistent Cart & Wishlist**: Utilizing Redux state paired with LocalStorage and DB synchronization, ensuring user selections survive app reloads and browser refreshes.
3. **Simplified Admin Center**: A focused dashboard providing real-time store statistics, instant CRUD product catalogs, and order status tracking to streamline day-to-day storefront operations.
